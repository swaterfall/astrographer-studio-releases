# Astrographer Studio

Downloads and updates for [Astrographer Studio](https://astrographer.app),
an app to stack, process and finish astrophotos.

This repository holds the releases only; the app's source is private.

## Download

Get the latest version from [Releases](https://github.com/swaterfall/astrographer-studio-releases/releases/latest):

| Platform | File |
| --- | --- |
| Mac with Apple silicon (M1 and later) | `Astrographer-Studio-<version>-apple-silicon.dmg` |
| Mac with an Intel processor | `Astrographer-Studio-<version>-intel.dmg` |
| Windows 10 and 11 (64-bit) | `Astrographer-Studio-<version>-windows-x86_64.zip` |
| Linux (x86_64, glibc 2.35 or later) | `Astrographer-Studio-<version>-x86_64.AppImage` |

**Mac:** open the disk image and drag Astrographer Studio to Applications.

**Windows:** unzip it and run `Astrographer Studio.exe`.

**Linux:** make the AppImage executable (`chmod +x`) and run it. On Ubuntu
22.04, install `libfuse2` first. A `.tar.gz` is there too, to install by hand.

Checksums are in the `SHA256SUMS` file of each release.
